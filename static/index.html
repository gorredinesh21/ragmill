What's under the hood

Hybrid search beats vector-only

Keyword search nails exact terms like "HNSW"; vector search nails paraphrases. Fusing both wins on our measured eval: hit@10 0.72 vs 0.67 dense-only, MRR 0.36 vs 0.31 (raw eval JSON, 60 golden queries — rerun it yourself via POST /api/eval).

Million-document ingest

Embeddings run inside the containers (no embedding API quotas), as parallel sharded Cloud Run jobs. Every document ID is deterministic, so a crashed job just re-runs and overwrites — the count never double-counts.

Honest, cheap demo

This page runs on a scale-to-zero Cloud Run service that costs < $1/month. No LLM key configured? Answers fall back to a clearly-labeled extractive mode — nothing pretends to be something it isn't.

Why keyword + vectors together win: vector search retrieves by meaning and misses rare exact terms; keyword search retrieves exact terms and misses paraphrases. Reciprocal Rank Fusion merges both rankings, and each engine covers the other's failure mode — measured above.
